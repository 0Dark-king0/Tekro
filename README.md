# 🎵 تكرو (Tekro)

بوت ديسكورد لمكتبة موسيقى شخصية، مع لوحة تحكم تفاعلية داخل ديسكورد وكلمات متزامنة تتحدث حية أثناء التشغيل، بالإضافة إلى لوحة ويب لإدارة المكتبة.

## المميزات

- مكتبة MP3 محلية (`library/music`) مع ملفات كلمات LRC مطابقة (`library/lyrics`)
- **مقفول على سيرفر واحد فقط** عبر `DISCORD_GUILD_ID` — يرفض يشتغل أو ينسحب من أي سيرفر ثاني
- تسجيل أوامر لحظي (instant guild sync) بدل الانتظار العالمي
- **لوحة تحكم تفاعلية (`/panel`)**: أزرار تشغيل/إيقاف، تخطي، تكرار، صوت، ومكتبة (Select Menu) — أي حد بالروم الصوتي يتحكم فيها
- **كلمات متزامنة حية** تتحدث داخل نفس الرسالة بنمط:
  ```
  -# السطر السابق
  ### السطر الحالي
  -# السطر القادم
  ```
  التحديث محسوب (coalesced) بحد أقصى مرة كل ~1.1 ثانية لتفادي حظر Discord مهما كانت الأغنية سريعة
- **Queue**: تشغيل أغنية وأنت شغّال ثانية = تنضاف للقائمة تلقائياً
- **Loop** بثلاث أوضاع: متوقف / أغنية واحدة / القائمة كاملة
- **Volume** تفاعلي من 0% لـ 200%
- **Auto-disconnect** لو البوت صار وحيد بالروم لأكثر من دقيقتين
- أوامر: `/play`, `/panel`, `/library`, `/stop`, `/skip`, `/volume`, `/loop`, `/nowplaying`, `!join`, `!leave`
- لوحة ويب لرفع/حذف/تشغيل المقطوعات، مع جلسات آمنة (session tokens) وحماية من محاولات تسجيل الدخول المتكررة
- أسماء الملفات تدعم المسافات والعربي بالكامل: يتخزن الملف بصيغة آمنة على القرص، ويظهر بالاسم الأصلي بلوحة الويب وديسكورد
- لا يحتاج قاعدة بيانات — كل شي ملفات محلية + JSON بسيط للأسماء

## تطابق الملفات

استخدم نفس اسم الملف الأساسي:

```text
library/music/اغنية حماسية.mp3
library/lyrics/اغنية حماسية.lrc
```

ملف الـ LRC اختياري؛ المقطوعات بدون كلمات تشتغل عادي بدون عرض متزامن.

## الإعداد المحلي

1. ثبّت Python 3.11+ و FFmpeg.
2. انسخ `.env.example` إلى `.env`.
3. حط توكن البوت بـ `DISCORD_TOKEN`.
4. حط كلمة سر قوية بـ `WEB_PASSWORD`.
5. **مهم**: حط الـ ID حق سيرفرك بـ `DISCORD_GUILD_ID` عشان القفل الأمني يشتغل والأوامر تتسجل فوراً.
6. ثبّت المكتبات:

```bash
pip install -r requirements.txt
```

7. شغّل:

```bash
python start.py
```

افتح لوحة الويب على `http://127.0.0.1:10000`.

## صلاحيات بوت ديسكورد

ادعُ البوت بهذي الـ scopes:

- `bot`
- `applications.commands`

وصلاحيات للبوت:

- View Channels
- Send Messages
- Connect
- Speak
- Use Voice Activity

البوت يحتاج صلاحية بالقناة النصية اللي يظهر فيها لوحة التحكم/الكلمات.

## Render

المشروع يستخدم ملفات محلية للمكتبة الحالية. على Render، الملفات المحلية مو تخزين دائم على الخدمات ephemeral — لو انبنى الـ instance من جديد ممكن الأغاني تروح. لمشروع شخصي صغير هذا مقبول؛ لاحقاً ممكن ننقل `library/music` و `library/lyrics` لتخزين خارجي (object storage) مع قاعدة بيانات للـ metadata.

`render.yaml` موجود كنقطة بداية. أضف متغيرات البيئة بلوحة Render وانشر.

## لوحة الويب

تستخدم كلمة سر واحدة من `WEB_PASSWORD`، مع جلسات (session tokens) عشوائية بدل تخزين كلمة السر نفسها بالكوكي، وحماية rate-limit على تسجيل الدخول (5 محاولات كل 5 دقائق).

## صيغة LRC

التوقيتات القياسية مدعومة:

```text
[00:12.30] السطر الأول
[00:15.80] السطر الثاني
[00:19.10] السطر الثالث
```

أكثر من توقيت بنفس السطر مدعوم كمان.
